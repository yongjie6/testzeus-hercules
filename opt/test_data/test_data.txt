# 被测对象：微信小程序（小量动机）

本项目测试的是微信小程序，不是网页。

## 工具约束（重要）

所有页面操作必须通过 MCP 工具完成，工具名以 mmcp_wxmp_ 开头。
target_helper 应始终为 mcp。

禁止使用任何浏览器工具：open_url、click、get_interactive_elements、
get_page_text、geturl 等。小程序不是网页，浏览器工具在这里全部无效。
不要试图用 URL 打开小程序页面。

## 操作方式

1. 每条用例开始，先用 mmcp_wxmp_mp_login_as 设置前置态：
   - logged-in：已登录用户（Neo）
   - guest：未登录
   不要去驱动登录界面，微信授权弹窗是原生 UI，自动化点不到。

2. 跳转页面用 mmcp_wxmp_mp_navigate，传路由名而不是路径：
   login / home / chat / mine / luxxTest / unregister / webview

3. 不确定页面上有什么时，先用 mmcp_wxmp_mp_snapshot 查看。
   它会列出当前页所有可见文案和控件。

4. 点击用 mmcp_wxmp_mp_tap_text，传可见文案（例如"退出登录"）。
   不要用 CSS 选择器或 class 名。

5. 断言基于 mmcp_wxmp_mp_snapshot 的输出判断文案是否存在。
